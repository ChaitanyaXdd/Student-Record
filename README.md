# Student Record System

A **Spring Boot** application for managing student records with **JWT authentication, Spring Security 6, and Role-Based Access Control (RBAC)**.

## Features

- **Student Management**: Add, update, view, and delete student records.
- **Authentication & Authorization**:
  - **JWT-based authentication** for secure API access.
  - **Spring Security 6** for access control.
- **Role-Based Access Control (RBAC)**:
  - Different user roles (**Admin, Teacher, Student**) with restricted permissions.
- **Secure API Endpoints**: Role-based access control for different functionalities.
- **Spring Boot & REST API**: Fully developed using **Spring Boot** with a RESTful API.

## Tech Stack

- **Backend**: Spring Boot, Spring Security 6, JWT
- **Database**: PostgreSQL
- **Build Tool**: Maven
- **Authentication**: JSON Web Token (JWT)
- **Security**: Role-Based Access Control (RBAC)
